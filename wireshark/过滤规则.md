- 按照地址过滤：
	- 想看源IP为XX的包：ip.src == 192.138.0.10
	- 想看目标IP为XX的包：ip.dst == 192.138.0.10
	- 想看源IP或目标IP为XX的包：ip.addr == 192.168.182.55
- 按照MAC地址：
	- 想看源MAC为XX的包：eth.src == 00-E0-70-D0-6A-AE
	-  想看目标MAC为XX的包：eth.dst == 00-E0-70-D0-6A-AE
	-  想看源MAC或目标MAC为XX的包：eth.addr == 00-E0-70-D0-6A-AE
- 按照端口号过滤：
	- 过滤TCP端口为4694的包：tcp.port == 4694
	- 过滤源端口为4694的包：tcp.srcport == 4694
	- 过滤目标端口为4694的包：tcp.dstport == 4694
- 按协议类型过滤：
	- 直接写协议类型如：arp、dfcp
- 规则组合 ：
	- and：只想看某台电脑的dhcp包如dhcp and eth.addr == 00-E0-70-D0-6A-AE
	- or：想看dhcp或arp
	- ！：想看除了arp之外的其他包如！arp

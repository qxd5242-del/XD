二.用户管理

	 - 用户登录和注销
	 - 少用root账号登陆，可以利用普通用户登陆，再用“su - 用户名”命令来切换管理者身份
	 - 输入“logoud”即可以注销用户，不过在图形运行级别无效，在运行级别3下有效
   
- 创建用户
	- 用”useradd -m 用户名“来添加目录，默认该用户的家目录在/home/该用户名
	- 也可以通过“useradd -d 指定目录 新的用户名”给新创建的用户指定家目录
  
- 指定/修改密码
	- passwd 用户名
	- pwd用于显示当前用户所在的目录
- 删除用户
	- 删除用户milan，但是保留家目录用userdel milan
	- 删除用户以及用户的主目录用userdel -r tom
	- 一般情况下建议保留家目录
- 查看用户信息指令
	- id 用户名
- 查看当前用户/登录用户
	- whoami（可看登陆IP）
- 用户组
	- 新增用户组：groupadd 组名
	- 删除用户组：groupdel 组名
	- 添加用户时候直接加上组：useradd -g 用户组 用户名
	- 修改用户的组：usermod -g 用户组 用户名
- 用户和组的相关文件
	- /etc/passwd 文件：
		- 用户的配置文件，记录用户的各种信息
		- 每行的含义：用户名：口令：用户标识号：组标识号：注释性描述：主目录：登陆shell
		- 比如：vim /etc/pas
	- /etc/shadow 文件
		- 口令的配置文件
		- 每行的含义：登录名：加密口令：最后一次修改时间：最小时间间隔：最大时间间隔：警告时间：不活动时间：失效时间：标志
	- /etc/group 文件
		- 组的配置文件，记录Linux包含的组的信息
		- 每行含义：组名：组标识号：组内用户列表

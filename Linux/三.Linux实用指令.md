- 运行级别：
	- 0：关机
	- 1：单用户（找回丢失的密码）
	- 2：多用户状态没有网络服务（不常用）
	- 3：多用户状态有网络服务（常用）
	- 4：系统未使用保留给用户（不常用）
	- 5：图形界面（常用）
	- 6：系统重启
	- 可以用init切换运行级别，如“init 0”
	- 可以查看当前运行级别，可以修改默认运行级别
- 可以找回root密码
- 在Linux隐藏文件是以“.”开头的
- 帮助指令：
	- man （如man ls）
	- help
	- 英语不好百度也行
- 文件目录指令类：
	- pwd指令：显示当前工作目录的绝对路径（也可以直接用realpath a.txt）
		- 区分：绝对路径是从根目录开始的，相对路径是从当前目录开始的（如绝对路径：/home/tom/a.txt，相对路径：tom/a/txt）
	- ls指令：
		- -a：显示当前目录下的所有文件和目录，包括隐藏的
		- -l：以列表的方式显示信息
		- -lh：将文件的信息（如文件大小）转化为人为的更方便的形式
	- cd指令：
		- 回到自己的家目录用“cd”
		- 回到当前目录的上一级目录：cd ..
	- mkdir指令：用于创建目录
		- 创建单一目录：madir /home/a
		- 创建多级目录：mkdir -p /home/a/b
	- rmdir指令：删除空目录
		- 删除非空目录(谨慎，会删除整个文件)：rm -rf 要删除的目录
	- touch指令：创建空文件
	- cp指令：拷贝文件到指定目录
		- 如将 /home/hello.txt 拷贝到 /home/bbb 目录下（cp hello.txt /home/bbb）
		- 也可以递归复制整个文件夹，如将 /home/bbb 整个目录拷贝到 /opt
		 (cp -r /home/bbb /opt)
		- 强制覆盖不提示的方法: \cp -r /home/bbb /opt
	- rm指令：删除文件或目录 
		- 递归删除整个文件：-r
		- 强制删除不提示：-f
		- 案例1：将 /home/hello.txt 删除  （rm /home/hello.txt）
		- 案例2：递归删除整个文件夹不提示，这个要小心 （rm -rf /home/bbb）
	- mv指令：移动文件与目录或重命名
		- 将文件移动到同一个目录下，也就是重命名，如 mv car.txt pig.txt
		- 将文件移动到不同目录下的地方同上
		- 将文件移动并且重命名：mv pig.txt /root/bird.txt
		- 移动整个文件也是 ”mv 旧目录名 新的目录名“的格式
	- cat指令：查看文件内容，不能修改，相对于vim更安全
		- -n：显示行号 （如cat -n /etc/profile）
		- 为了浏览方便，一般会带上管道命令 | more（管道命令：类似于把前面的结果交给下一个指令进行处理）
	- more指令：是一个基于VI编辑器的文本过滤器，它以全屏幕的方式按页显示文本文件的内容，more指令中内置了若干快捷键（交互的命令）
		- 基本语法：more 要查看的文件
		- 快捷键：
			- 空白键：向下翻一页
			- Enter：向下翻一行
			- q：代表立即离开more，不再显示该文件的内容
			- Ctrl + F：向下滚动一屏
			- Ctrl + B：向上滚动一屏
			- =：输出当前行的行号
			- :f ：输出文件名和当前行的行号
	- less指令：用来分屏查看文件内容，它的功能宇more指令类似，但是比more指令更加强大，支持各种显示终端。less指令在显示文件内容时候根据显示需要加载内容，对于大型文件具有较高的效率
		- 基本语法：less 要查看的文件
			- 空白键：向下翻动一页
			- [pagedown]：向上翻动一页
			- /字符：向下搜寻“字符”的功能
				- n：向下查找
				- N：向上查找
			- q：离开less这个程序
	- echo指令：输出内容到控制台
		- 例如：echo $HOATNAME、echo "hello,world"
	- head指令：用于显示文件的开头部分，默认显示前面10行内容
		- 语法：
			- 默认：head 文件
			- 查看文件前5行：head -n 5 文件名（如head -n 5 /etc/profild）
	- tail指令：用于输出文件末尾的内容，默认显示文件末尾的前10行内容
		- 语法：
			- 默认：tail 文件
			- 查看文件末尾的前5行：tail -n 5 文件名（如tail -n 5 /etc/profild）
			- tail -f 文件（实时监控该文档的所有更新，用完该指令之后可以再开一个终端来编写原文件进行查看）
	- “>”指令和“>>”指令：“>”是覆盖，“>>”是追加
		- ls -l>文件 （列表的内容覆盖到文件中）
		- cat 文件1 > 文件2 （将文件1的内容覆盖到文件2）
		- cat 文件1 >> 文件2 （将文件1的内容追加到文件2）
		- echo "内容" >> 文件（追加）
	- In指令：软链接也称为符号链接，类似于windows的快捷方式，主要存放了连接其他文件的路径
		- 基本语法：In -s [原文件或目录] [软连接名]（功能：给原来的文件创建一个软连接）
		- 案例：在/home 目录下创建一个软连接 myroot，连接到/root目录
			In -s /root /home/myroot
		- 删除还是用rm
		- 细节说明：当我们使用pwd查看目录时，仍然看到的是软连接所在的目录
	- history指令：查看已经执行过的指令，也可以执行历史指令
		- 显示所有历史指令：history
		- 显示最近使用的10个指令：history 10
		- 执行历史编号为5的指令：!5
- 时间日期类指令：
	- data指令：
		- data ：显示当前时间
		- date +%Y ：显示当前年份
		- date +%m ：显示当前月份
		- date +%d：显示当前是哪一天
		- date “+%Y-%m-%d %H:%M:%S” ：显示年月日时分秒
		- 设置系统时间：date -s "要设置的时间"
	- cal：查看当前日历信息指令
		- 显示整年的日历：cal 年份
		- 显示当前日历：cal
- 搜索查找类指令：
	- find指令：从指定目录向下递归的遍历各个子目录，将满足条件的文件或者目录显示在终端
		- 基本语法：
			- find 指定目录 -name 要查找的文件名：按文件名字查找
			- find 指定目录 -user  用户名：查找属于指定用户的所有文件
			- find 指定目录 -size 文件大小：按文件大小查找（“+”大于，“-”小于，无符号为等于，单位有k，M，G）
				- 例如：查找整个Linux系统下的大于200M的文件： find / -size +200M
	- locate指令：无需遍历整个文件系统，可以快速定位文件路径，基于数据库进行查询，使用locate之前必须用updatedb指令创建locate数据库
		- 基本语法：locate 文件名
	- which指令：直接用which 所搜索的目标（如：which ls）
	- grep指令和管道符 | ：过滤查找，“|”表示前一个命令的处理结果传递到后面的命令处理
		- 基本语法：
			- grep 选项 查找内容 源文件
				- 选项：
					- -n :显示匹配行以及行号
					- -i :忽略字母大小写
		- 实例：在hello.txt文件中查找“yes”所在行，并且显示行号
			写法一：cat /home/hello.txt | grep "yes"
			写法二：grep -n "yes" /home/hello.txt
- 压缩和解压类文件：
	- gzip/gunzip 指令：gzip用于压缩文件，gunzip用于解压文件
		- 案例：将/home下的hello.txt文件进行压缩和解压
			 压缩：gzip /home/hello.txt
			 解压：gunzip /home/hello.txt.gz
	- zip/unzip指令：zip用于压缩，unzip用于解压
		- 案例：将 /home下的所有文件或文件夹进行压缩成myhome.zip
			 zip -r myhome.zip /home/ (将home目录以及包含的文件和子文件夹都压缩)
		- 案例：将myhome.zip解压到/opt/tmp 目录下（可以先用mkdir /opt/tmp创建一个文件夹）
			 unzip -d /opt/tmp /home/myhome.zip (不加-d的话会默认解压到当前的文件夹)
	- tar指令：是打包指令，最后打包的文件是.tar.gz的文件
		- 案例1：将 /home/pig.txt和 /home/cat.txt压缩成pc.tar.gz
			 tar -zcvf pc.tar.gz /home/pig.txt /home/cat.txt
		- 案例2：将pc.tar.gz解压到 /opt/tmp2目录下
			 tar -zxvf /home/pc.tar.gz -C /opt/tmp2（如果不加“-C /opt/tmp2”，则会解压到当前目录下）

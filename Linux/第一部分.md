- “/”为根目录，Linux世界里一切皆文件
- 常用：
	- /bin ：是Binary的缩写，存放着最经常使用的命令
	- /sbin ：存放的是系统管理员使用的系统管理程序
	- /home ：存放普通目录的主目录，在Linux中每个用户都有一个自己的目录，一般目录名是以用户的账号命名
	- /root ：系统管理员，也称作超级权限者的用户主目录
	- /lib ：系统开机所需要的最基本的动态连接共享库，其作用类似于Windows里面的DLL文件，几乎所有的程序都需要用到这些共享库
	- /lost + found ：一般情况下是空的，当系统非法关机后，会存放一些文件
	- /etc ：所有的系统管理所需要的配置文件和子目录，比如安装MySQL数据库 my.conf
	- /usr ：用户的很多应用程序和文件都放在这个文件上类似于Windows下的program files目录
	- /boot：存放Linux启动时使用的一些核心文件，包括一些连接文件和镜像文件
	- /proc ：虚拟的目录，不能动，是系统内存的映射，访问这个目录来获取系统信息
	- /srv ：不能动，存放一些服务启动之后需要提取的数据
	- /sys ：不能动
	- /tmp ：存放一些临时文件
	- /dev ：类似于Windows的设备管理器，把所有的硬件用文件的形式存储
	- /media：Linux系统会自动识别一些设备，例如U盘，光驱等识别后的设备会被挂载到这个目录下
	- /mnt ：系统提供该目录是为了让用户临时挂载别的文件系统，我们可以将外部的存储挂载在这上面，然后进入该目录就可以查看里面的内容了
	- /opt ：给主机额外安装软件所存放的目录，默认为空
	- /usr/local：另一个给主机额外安装软件的目录。一般通过编译源码方式安装的程序
	- /var ：存放在不断扩充的东西，习惯将经常被修改的目录放在这个目录下，包括各种日志文件
	- /selinux ：是一种安全子系统，他能控制程序只能访问特定文件，有三种工作模式，可以自行设置
- vim ：可以用这个从物理机上传文件到虚拟机的某一个目录里面，用cd ~\Desktop切换到桌面，再用ls查看完之后可以在用scp传输，比如 scp .\p48.jpg apple@192.168.182.128:/home/apple/Pictures/。还可以用vim去写一个文件，比如vim Hello.Java
  - vim快捷键（要在一般模式下操作）：
		- 拷贝当前行 yy，拷贝当前行向下的5行 5yy，粘贴 p
		- 删除当前行 dd，其他同上
		- 查找某个单词（命令行下：或者/关键字后输入要查找的单词，回车，输入n就是查找下一个）
		- 设置行号 set nu，取消行号 set nonu
		- 使用快捷键到文档的最末行 G，到最首行 gg
		- 撤销动作 u
		- 定位行数如 20 shift+g
		- “：q” 如果文件没有被修改，直接退出
		- “：q！” 强制退出且不保存任何修改
		- “：wq” 保存并退出
- 关机重启命令：
	- shutdown -h now（立刻进行关机）
	- shutdown -h 1 （会给用户都发一条“hello，1分钟后会关机了”）
	- shutdown -r now （现在重新启动计算机）
	- halt （关机作用和上面一样）
	- reboot （重启计算机）
	- sync （把内存数据同步到磁盘）
	- 注意：重启或者关闭系统之前最好用sync将数据同步到磁盘中
- 列出当前目录下文件、目录可以用ls
- 切换目录用 cd ，比如 cd /home/
- 从目录返回至原状态可以只写一个 cd

- 文件都有所有者，所有组，其他组，Linux中每一个用户都必须属于一个组
- 查看文件的所有者：ls -ahl
- 修改文件所有者：chown 新用户名 文件名
		例如将apple.txt的所有者从root改为tom：chown tom apple.txt
- 组的创建：groupadd 组名
- 修改文件所在组：chgrp 新组名 文件名/目录
- 改变用户所在组：
	- usermod -g 新组名 用户名
	- usermod -d 目录名 用户名（改变该用户登陆的初始目录，用户需要有进入到新目录的权限）
- ls -l（也可以缩写为ll）显示的内容示例如下：
		-rwxrw-r-- 1 root root 1213 Feb 2 09:39 abc
	- 第0位确定文件类型：（d, -, l, c, b）
		- d：目录
		- -：空
		- l：链接
		- c：字符设备文件，鼠标，键盘等
		- b：块设备：蔽日硬盘
	- 第1~3位确定文件所有者拥有的权限，4~6位确定同用户组拥有的权限，7~9位确定其他用户拥有的权限
	- 也可以用数字表示：r=4，w=2，x=1，rwx=7
	- 对于文件夹/目录：
		- x：表示可以进入到该目录，如cd
		- r：表示可以ls，将目录的内容显示
		- w：表示可以在该目录删除或创建文件
	- 对于文件：
		- rwx分别表示可以读写执行
- 修改文件或者目录的权限
	- 方式一：+、-、=变更权限，u：所有者；g：所有组；o：其他人；a：所有人
		- 直接看案例：
			- 1.给abc的所有者读写执行的权限，给所在组读执行权限，给其他组执行的权限
				chmod u=rwx,g=rx,o=x abc
			- 2.给abc的所有者出去执行的权限，增加组写的权限
				chmod u-x,g+ w abc
	- 方式二：通过数字变更权限
		- 案例：将 /home/abc.txt 文件的权限修改为 rwxr-xr-x,使用数字的方式实现
			chmod 755 /home/abc.txt
- 修改文件/目录所有者
	- 只改变所有者：chown 新所有者名 文件/目录
	- 同时改变所有者和所有组：chown 新的所有者名 新的所有组名 文件/目录
	- 如果是目录，则使其所有子文件或者目录递归生效：加上-R
- 修改文件/目录所在组：chgrp 新组名 文件/目录
